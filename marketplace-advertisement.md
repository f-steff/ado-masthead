# Masthead

Masthead is being developed to provide context-aware pull request reviews for
Azure DevOps. Reviews will use selectable lenses, inline findings, a review
guide and continuing discussion with PR authors.

## Development status

This early package contains the local review core and an informational
organization-settings page. It does not install service hooks, deploy a review
pipeline, or review PRs inside Azure DevOps. Packaging is available for development validation;
publishing and production use remain disabled.

See the [project README](https://github.com/f-steff/ado-masthead#readme) for
the current implementation status and local testing instructions.
