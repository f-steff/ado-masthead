About Masthead in this project

Version loading...

Masthead reviews are gated at three levels: the organization master switch, this project switch, and each repository switch. A pull request is reviewed only when all three are enabled.

Use General to enable the project, choose what a newly discovered repository inherits, and turn individual repositories on or off. New repositories are disabled unless the project default says otherwise.

Use Review profile to inherit the organization's provider, model, lenses and review guide, or to override them for this project. Each repository can have its own override as well.

The destination repository decides the gate. A pull request from a fork or another project is checked against the project and repository that receive the merge.

Organization administrators control the master switch, defaults, event delivery, central pipeline and the default review profile on the organization settings page.

Provider keys are never entered here. They belong in an Azure DevOps secret variable group linked only to the central review pipeline.
